# Coder - Digital Agency (Node.js + MySQL Laragon) - Database Bahasa Indonesia

1. Start MySQL di Laragon, buka HeidiSQL, jalankan `database.sql` (File > Run SQL file).
   Database baru bernama `agensi_digital` (database lama `digital_agency` tidak disentuh).
2. Buka terminal di folder project:
       npm install
       npm start
3. Website: http://localhost:3000     Admin: http://localhost:3000/admin.html
   (login admin pertama kali = buat akun admin)

Nama tabel: kategori_layanan, layanan, anggota_tim, klien, proyek, tim_proyek,
testimoni, faq, status_pesan, pesan_masuk, admin.
